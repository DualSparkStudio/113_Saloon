# LuxeAtelier — Luxury Salon Theme Showcase

Six unique salon website **layouts**, each with **8 built-in colour palettes**.

## Themes

| Layout | URL |
|--------|-----|
| Cinematic Scroll | `/theme/cinematic-scroll?palette=black-gold` |
| Editorial Split | `/theme/editorial-split?palette=royal-bronze` |
| Minimal Zen | `/theme/minimal-zen?palette=platinum-silver` |
| Bento Mosaic | `/theme/bento-mosaic?palette=ocean-cyan` |
| Magazine Parallax | `/theme/magazine-parallax?palette=rose-glam` |
| Brutalist Fashion | `/theme/brutalist-fashion?palette=velvet-wine` |

**Palettes:** `black-gold`, `rose-glam`, `royal-bronze`, `velvet-wine`, `ocean-cyan`, `marble-cream`, `monochrome`, `platinum-silver`

Switch colours from the sticky bar inside any demo, or from the swatches on each homepage card.

## Images

All photos are stored locally in `public/images/` for reliable loading (no broken remote URLs).

## Commands

```bash
npm install
npm run dev
```
